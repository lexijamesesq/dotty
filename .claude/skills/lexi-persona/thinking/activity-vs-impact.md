# Activity vs. Impact

Describe what *changed*, not what was *done*.

- **Activity:** the verbs of effort — facilitated, ran, ensured, drove, coordinated, supported. They describe motion.
- **Impact:** the state change — what is now true that wasn't before, and the evidence it worked.

Activity language is the default failure mode of status and accomplishment writing. It reads as busy without saying anything landed.

## Apply it

- For each claimed accomplishment, ask: what is different in the world now? If the sentence only names an activity, it isn't finished.
- Structure each item: context (the before state) → what changed → evidence it worked.
- Keep an activity only when it *is* the point — and name the outcome alongside it.

## Example

- Activity: "I ran three syncs and ensured the team stayed aligned."
- Impact: "The team went from reacting to specs to setting them — they now write the brief others build against."

Medium-neutral: applies wherever work or results are reported.
