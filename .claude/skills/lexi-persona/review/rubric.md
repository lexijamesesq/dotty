# Review Rubric

Adversarial. Used only by the review operation. Generate and refine never load this file.

Review a draft against the checks below. For each finding, name the specific failure and cite the words. Produce findings only — the caller decides what to fix. Do not edit the draft.

## Voice failures

- A claim softened below the author's conviction (could / might / potentially where a position is held), OR inflated above its evidence (transformed / game-changing / unprecedented).
- A sentence that describes where it should assert — a label ("Assessment Setup Time") where a claim belonged.
- An abstraction where a concrete instance was available.
- A buried lead — the most important point is not first.
- Corporate / AI phrasing: leverage, drive outcomes, facilitate alignment, the practical upshot.
- Passive voice hiding the actor.

## Substance failures

- Activity language where an outcome was the real content ("I facilitated / ran / ensured" with no what-changed).
- A missing through-line — sections that don't connect to one argument.
- A `[NEEDS: ...]` marker left unfilled — an open gap, not a finished draft.
- Vague generality presented as a claim ("significant advantages" — which ones?).

## Discipline

- Can 20% be cut? Try. Name the cuttable spans.
- Is the thesis restated where it was already made?
- Are any presented "alternatives" real choices, or false exploration?

## Calibration of the review itself

Be adversarial — if you found nothing, look harder; a clean draft is rare. But do not invent failures: every finding cites specific words. Flagging a vivid-but-true line ("a flaming disaster") as overstatement is a miscalibration — bluntness about something real is in voice.
